Problem Statement & Motivation

  • GDPR's "Right to be Forgotten" requires organizations to delete personal data from ML models upon user request
  • Naïve solution: Retrain from scratch — prohibitively expensive for large models (hours to days)
  • Approximate unlearning modifies model weights to "forget" specific data — but how do we certify it actually worked?
Core Research Question: Can we build a unified unlearning framework that operates at both class-level and sample-level, AND rigorously audit whether information has been truly removed using information-theoretic metrics?
  • Two-pronged approach: (1) A novel unlearning method (IWEUP v2) + (2) A PID-based auditing framework using Residual Knowledge (I∩)
  • Key insight: Traditional metrics like Forget Accuracy are misleading — a model can change predictions without removing memorized information

Literature Review

Exact Unlearning

SISA (Bourtoule et al., 2021) — Shards training data; retrains only the affected shard. Exact guarantees but impractical at scale.

Certified Removal (Ginart et al., 2019) — Newton step-based removal. Limited to convex models.

Foundation

Approximate Unlearning

Gradient Ascent (Thudi et al., 2022) — Maximize loss on forget set. Unstable.

SCRUB (Kurmanji et al., 2023) — Student-teacher distillation. High variance.

SalUn (Fan et al., 2024) — Saliency masks for selective weight updates.

Bad Teacher / Amnesiac — KD and gradient subtraction approaches.

Baselines (7 methods)

Auditing Unlearning

EACL 2026 (Mazzetto et al.) — Information Decomposition for LLM unlearning using PID and RINE estimator.

Key metric: Residual Knowledge (I∩) — shared information between base and unlearned model.

Our adaptation: First application to CNN-based (ResNet) unlearning.

Our Innovation
Gap identified: No prior work combines (1) a unified class+sample-level unlearning method with (2) information-theoretic auditing for vision models.

Research Objectives

  • Objective 1: Design a unified unlearning framework (IWEUP v2) that handles both class-level and sample-level forgetting with a single architecture
  • Objective 2: Adapt the Partial Information Decomposition (PID) framework to build a representation-level auditing system for CNN-based unlearning
  • Objective 3: Develop a stress-test protocol using difficulty-ranked forget sets (easy, hard, random) to evaluate unlearning robustness
  • Objective 4: Benchmark against 7 baselines on CIFAR-10/100 using both traditional metrics (MIA, accuracy) and information-theoretic metrics (I∩)
  • Objective 5: Demonstrate that I∩ is a more reliable auditing signal than Forget Accuracy for certifying unlearning compliance
Novelty Target: We are the first to (1) apply PID-based auditing to vision model unlearning, (2) introduce a stress-test protocol with I∩-ranked difficulty splits, and (3) empirically prove that Forget Accuracy is a misleading metric.

Novelty & Contributions

Unlearning Method (IWEUP v2)

  • Unified framework — auto-adapts to class vs. sample-level forgetting
  • Maximum Entropy Regularization — stable target state (uniform predictions)
  • Three-component sample-level loss: Adaptive Confidence Reduction + Anti-Memorization + MIA-Fooling
  • Result: MIA = 0.000 on both datasets, matching retrain

Auditing Framework (Novel)

  • RINE estimator ported from LLMs → ResNet using hook-based activation extraction
  • Per-sample I∩ difficulty scoring — ranks how hard each sample is to forget
  • Stress-test protocol — 3 difficulty splits evaluate robustness
  • Key finding: ForgetAcc ≠ information removal. I∩ is the true signal
Headline Result: Fine-tune (ForgetAcc=49%) and Gradient Ascent (ForgetAcc=37%) have nearly identical I∩ (0.193 vs 0.174) — proving Forget Accuracy measures behavioral change, not information removal.
